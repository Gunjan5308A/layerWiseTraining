Layer-Wise Phase

Each of 12 layers trains for 10 steps at a time.
• Active layer: requires_grad=True, LR ramps 10%→100% over 8 steps
• Previous layer: requires_grad=True, ramps 100%→10% over 3 steps
• All others: requires_grad=False, LR=0 (hard frozen)
• wte, wpe, ln_f: always full LR
• 120 steps per full cycle (12 layers × 10 steps)
• Step 0: skip (noisy gradient)
• Steps 1-3: grad_clip=0.5 (tighter)

EMA Sync (end of cycle)

After all 12 layers train once, EMA sync runs.
• Each inactive layer blended toward nearest trained layer
• w = 0.99 × w + 0.01 × trained_w
• No full unfreeze — VRAM stays flat
• Zero extra gradient tensors
• Then cycle resets to layer 0
Speed: 500ms

Architecture Summary

ALGORITHM
──────────────────────────────────────────────────
  for each cycle:
    for layer i in [0..11]:
      L{i}   = ACTIVE  (requires_grad=True,  LR = base * ramp)
      L{i-1} = SOFT    (requires_grad=True,  LR = base * prev_pct)
      all others = FROZEN (requires_grad=False, LR = 0)
      skip step 0 (noisy gradient)
      steps 1-8: active LR ramps 10%→100%
      steps 1-3: prev LR ramps 100%→10%, grad_clip=0.5
      steps 4-10: prev at 10%, grad_clip=1.0
      reset Adam m,v on unfreeze
      gradient norm EMA smooths spikes

    EMA sync: each layer w = 0.99*w + 0.01*nearest_trained_w
    reset to layer 0, repeat

LOSS SPIKE REDUCTION (6 techniques, 0 VRAM cost)
──────────────────────────────────────────────────
  1. Active LR ramp:     10%→100% over 8 steps (smooth start)
  2. Prev LR ramp-down:  100%→10% over 3 steps (smooth exit)
  3. Skip first step:    don't step on step_in_group == 0
  4. Optimizer reset:    zero m, v on unfreeze (clean slate)
  5. Grad norm EMA:      scalar EMA, scale grads by ema/current
  6. Dynamic grad_clip:  0.5 for first 3 steps, then 1.0

VRAM BREAKDOWN (per training step)
──────────────────────────────────────────────────
  Gradients:  only 2 layers (active + prev) = ~4.5M params
  Optimizer:  only 2 layers (AdamW state = 2x mem)
  Activations: 1 micro-batch at a time (batch_size=1)
  Total:       ~1.2 GB peak on 4GB VRAM GPU

EARLY STOPPING
──────────────────────────────────────────────────
  Stop when val loss <= 1e-4
